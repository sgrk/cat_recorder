# 猫検出録画システム仕様書

## 📝 システム概要

外部カメラからの映像を常時録画し、1分間の動画ファイルとして保存します。保存された動画からフレームを抽出し、YOLOモデルで猫（class 0）を検出します。検出結果に基づき、動画を「猫動画フォルダ」へ移動または削除します。また、Web UIを通じてモデルや設定の管理を行い、猫の検出画像をリアルタイムで表示します。

## 📷 カメラ映像の録画と保存

- 録画方法: OpenCVのcv2.VideoCapture()を使用して外部カメラから映像を取得し、cv2.VideoWriter()で1分間の動画ファイルとして保存します。
- カメラ設定:
  - デバイスID: 外部カメラのデバイスIDを指定可能
  - 解像度: 幅と高さを設定可能（デフォルト: 1280x720）
  - FPS: フレームレートを設定可能（デフォルト: 30fps）
  - 録画時間: 1ファイルあたりの録画時間を設定可能（デフォルト: 60秒）
- 保存先フォルダ: 以下のフォルダに分けて保存します。
  - recordings: 一時的な録画ファイル
  - cat_videos: 猫が検出された動画
  - cat_images: 猫が検出された画像
  - models: YOLOモデルファイル
- 容量管理: 各保存先フォルダの合計容量が1GBを超えた場合、古いファイルから順に削除し、1GB以内に収めます。

## 🐱 猫の検出と動画の分類

- フレーム抽出: 保存された動画から指定間隔（デフォルト: 30フレーム）でフレームを抽出します。
- 物体検出:
  - モデル: Ultralytics YOLOモデルを使用（デフォルト: detect_kinako_best.pt）
  - 検出対象: 猫（class 0）
  - 信頼度閾値: 検出の信頼度閾値を設定可能（デフォルト: 0.5）
- 分類条件:
  - 猫検出閾値: 抽出したフレームのうち、猫が検出された割合が指定値（デフォルト: 50%）以上の場合、その動画を「猫動画フォルダ」へ移動
  - 検出画像保存: 猫が検出された画像を「猫画像フォルダ」に保存
  - 非検出動画: 猫が検出されなかった動画は削除

## 🌐 Web UIによる管理機能

- モデル管理:
  - アップロード: 新しいYOLOモデルファイルのアップロード
  - 切り替え: モデルの動的切り替え（プロセッサーの再起動を伴う）
- 設定変更: 以下の設定をWeb UIから変更可能です。
  - カメラ設定（デバイスID、解像度、FPS、録画時間）
  - 保存設定（各フォルダのパス、容量制限）
  - 処理設定（フレーム抽出間隔、猫検出閾値、信頼度閾値）
  - モデル設定（モデルパス、猫のクラスID）
  - Web UI設定（ホスト、ポート）
- ステータス表示:
  - 録画状態: 現在の録画状況
  - ストレージ使用量: 各フォルダの使用容量
  - 最新の検出: 最後に猫が検出された時刻と画像
  - 動画一覧: 録画中の動画と保存された猫動画のリスト
- システム管理:
  - モジュール再起動: カメラ、プロセッサー、ストレージの各モジュールを個別に再起動可能

## 🛠 使用技術

- プログラミング言語: Python
- ライブラリ:
  - OpenCV: 映像の取得と保存
  - Ultralytics YOLO: 物体検出
  - FlaskまたはFastAPI: Web UIの構築

## 🔄 処理フロー

1. 外部カメラから映像を取得し、1分間の動画ファイルとして保存します。
2. 保存先フォルダの容量をチェックし、1GBを超えている場合は古い動画ファイルを削除します。
3. 保存された動画から30フレームおきに画像を抽出します。
4. 抽出した画像をYOLOモデルで推論し、猫（class 0）の検出を行います。
5. 猫が検出された画像の割合が50%以上の場合、その動画を「猫動画フォルダ」へ移動します。そうでない場合は動画を削除します。
6. Web UIを通じて、モデルや設定の管理、ステータスの確認を行います。
